# Contributing

Thanks for your interest in this project! This is a personal portfolio, but feedback and suggestions are welcome.

## How to Contribute

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/improvement`)
3. **Commit** your changes (`git commit -m 'Add some improvement'`)
4. **Push** to the branch (`git push origin feature/improvement`)
5. **Open** a Pull Request

## Reporting Issues

If you find a bug or have a suggestion, please [open an issue](https://github.com/WAIYAH/MY-PORTFOLIO/issues) with a clear description.

## Code Style

- HTML: Edit source files under `src/pages/` and `src/partials/` — never hand-edit `dist/`, it's regenerated by `node build.js`. Semantic, accessible markup (WCAG 2.1 AA).
- Shared markup (nav, mobile menu, footer, `<head>` boilerplate) lives once in `src/partials/` — don't reintroduce per-page duplication.
- Site-wide values (domain, socials, email) live in `src/data/site.json`; per-page SEO metadata lives in `src/data/pages.json` — don't hardcode them into a page.
- CSS: Use the design system in `css/styles.css` — follow existing custom property conventions. Tailwind utility classes are compiled at build time (see `tailwind.config.js`'s `content` globs) — if you add markup in a new file type, add its path there too.
- JavaScript: Vanilla ES6+ — follow the modular IIFE pattern in `js/app.js`
- Indent with 2 spaces, UTF-8 encoding
- Run `npm run build` and check the console output for errors before committing
